# Advanced Machine Learning
## MSc DSBA, CentraleSupélec
### October - December 2026

Sources for the Advanced Machine Learning course for DSBA students.

Lecturer: Paul Dubois (<p.dubois@centralesupelec.fr>)
<br>
TA: Vuk Ignjatovic (<vuk.ignjatovic@centralesupelec.fr>)

Course description: [DOCX](COURSE%20DESCRIPTION_AML.docx), [PDF](COURSE%20DESCRIPTION_AML.pdf)

Exam:
Students must submit an individual project report.
The report should be ~5 pages long on the topic of their choice.
The project must involve at least one of the techniques seen during this course.
[Here](SUGGESTED_DATASETS.md) are some suggestions for datasets;
Feel free to use another one of your choice.

DCE: You are allowed to use compute clusters from the DCE, more informations [here](DCE_TUTORIAL.md).
